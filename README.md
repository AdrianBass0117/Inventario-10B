# Función:
    Proyecto web que realiza el registro y consulta de productos.

# Tecnologías:
    CSS 
    XAMPP:
        PHP 8.2.12
        MariaDB
        Apache
    

# Instalaciones:
    - Se debe instalar XAMPP versión 3.3.0 o superior
    - Instalar un navegador

# Configuración:
    - Descargar el proyecto en XAMPP/htdocs/(nombre_proyecto)
    - Abrir la carpeta del proyecto en un editor de codigo
    - Se deben activar los servicios Apache y MySQL de XAMPP desde el panel
    - Abrir un Gestor de BD
    - Se requiere crear una base de datos para el proyecto
    - Pegar el script base_datos.sql (que se encuentra en este proyecto) en la nueva DB creada y ejectura
    - Verificar el archivo de conexion.php y que los datos sean correctos 
    - Consultar la página web en el navegador con la url "localhost/(nombre que se le asigno a la carpeta del proyecto)/"
